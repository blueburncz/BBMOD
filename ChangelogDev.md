# Changelog dev

> This file is used to accumulate changes before a changelog for a release is created.

* Added missing property `PlaybackSpeed` to `BBMOD_AnimationPlayer`, causing a crash. This is used to play the animation at a faster/slower rate. Defaults to 1.
* Added support for loading triangle fans to `BBMOD_OBJImporter`. Thanks [@danielpancake](https://github.com/danielpancake) for contributing!
