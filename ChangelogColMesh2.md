# Changelog ColMesh2

* ColMesh v2 is now included with BBMOD. You can find its license in `LICENSE-ColMesh`, inside the datafiles folder.
* Added new functions `bbmod_mesh_to_colmesh2(_mesh, _colmesh[, _transform])` and `bbmod_model_to_colmesh2(_model, _colmesh[, _transform])`, which add a `BBMOD_Mesh` and `BBMOD_Model` into a ColMesh v2 respectively.
* Added new functions `bbmod_terrain_to_colmesh(_terrain, _colmesh)` and `bbmod_terrain_to_colmesh2(_terrain, _colmesh)`, which add a `BBMOD_Terrain` into a ColMesh v1 or v2 container respectively.
